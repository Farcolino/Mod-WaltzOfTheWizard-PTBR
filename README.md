=
  WALTZ OF THE WIZARD  ·  MOD DE VOZ EM PORTUGUES
=

  Lance feiticos falando em portugues.

  O jogo entende comando de voz, mas so em ingles. Este mod troca o
  reconhecedor por um modelo de portugues e ensina ao jogo mais de
  sete mil formas de dizer a mesma coisa - com as conjugacoes e os
  generos que a gente usa falando.

  Voce nao decora comando. Voce fala.

=
  COMO FUNCIONA A ESCALA
=

  Todo feitico de medida aceita intensidade. A mesma frase, mais forte:

      deixa isso maior                 um passo
      deixa isso muito maior           bem mais
      deixa isso absurdamente maior    o maximo
      deixa isso absurdamente gigante  o maximo, de uma vez

  Vale para tamanho, velocidade, forca e peso.

=
  FEITICOS EM VOCE MESMO
=

  Troque o alvo por "meu corpo":

      "deixe meu corpo maior"        "deixe meu corpo mais rapido"
      "deixe meu corpo saudavel"     "deixe meu corpo leve"

=
  Como Instalar o Mod?
=
   Vai precisar Baixar o MELONLOADER pois ele so funciona através dele
   
   1. Baixe o [MELONLOADER](https://melonwiki.xyz) pelo link
   2. Ao abrir o MELONLOADER selecione o WALTZ OF THE WIZARD EXTENDED EDITION e Instale
   3. Abra o jogo uma vez, para o MELONLOADER moddar o Waltz of the Wizard
   4. Feche o jogo e Baixe o mod atualizado
   5. Abra o mod na sua versão atual e avance até o final. Assim que terminar, abra o jogo ele ja vai estar com as dublagem, texturas e o Vosk em português.

  Comesse a jogar e se divirta!!
